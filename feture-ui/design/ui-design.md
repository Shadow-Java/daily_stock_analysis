## 一、设计原则

### 1.1 核心理念

这套 UI 的核心不是"好看的仪表盘"，而是**帮助用户建立每日的思考仪式**。每个交互点都应该服务于这个目的：

- **摩擦要刚好**：填写心理快照和信念假设有意设计成必须"停下来想一想"的步骤，不能太快跳过
- **记录要轻**：主流程（录入预期）应该流畅，避免繁琐表单感
- **反馈要及时**：收盘后的评分和偏差标注要清晰展示，不能埋在深处
- **成长要可见**：仪表盘不是"KPI 墙"，而是镜子——诚实、具体、有时间维度

### 1.2 视觉风格

沿用现有 DSA 设计语言：
- 浅色/深色主题双支持
- 主色调：`hsl(var(--primary))`（cyan）
- 功能色：红色（正确/上涨）、绿色（错误/下跌）、黄色（警告/偏差）
- 字体层级清晰，内容密度适中（不是交易终端，是思考工具）

### 1.3 布局系统

全屏左侧 sidebar + 右侧内容区（已在 Shell.tsx 中实现）。页面内容区最大宽度视页面类型：
- 录入/详情类页面：`max-w-2xl`（集中注意力）
- 列表/统计类页面：`max-w-4xl`（信息密度适中）
- 仪表盘：`max-w-5xl`（多列布局）

## 六、大盘情绪页面设计

> 日期：2026-09-21
> 状态：设计稿 v0.4（新增：量能轨迹、龙头/小弟识别、涨停时间筛选与板块分类、市场聚焦三档化；已重绘 mockup）

### 6.0 设计定位

大盘情绪页不是行情终端，也不是"当日快照"，而是一条**市场情绪的演化脉络**。它回答两个问题：

1. **今天的情绪是从哪走过来的**——前几天的情绪 → 现在；
2. **情绪正在往哪个方向走**——结合周期阶段，判断拐点与持续性。

- **时间维度是一等公民**：每一栏都有「昨日 → 今日」的增量与「近 N 日」的轨迹，禁止只给孤立的一帧
- **情绪是底色，事件/个股/板块是影子**：所有"热点"都放在情绪的演化背景下，判断它是「新周期起点」还是「最后一棒」
- **先结论后结构**：先给温度轨迹与周期阶段，再给梯队 / 事件 / 个股的连续过程，长尾默认折叠
- **只读为主**：唯一可写操作是「＋写入今日预期」

```
路由：/sentiment        Sidebar：🌡 大盘情绪        布局：max-w-5xl
```

### 6.1 页面总览 `/sentiment`

### 6.2 模块一：情绪演化主轴（含外盘先行锚）

#### 外盘情绪（美股隔夜 × 韩股今晨）

外盘是 A股情绪的「先行锚」：**美股 = 隔夜**（昨夜收盘，解释今日开盘情绪），**韩股 = 今晨**（8:00 开盘，与 A股盘中重叠，且为半导体权重市场）。

**指标选择**：

| 市场 | 指标 | 作用 |
|------|------|------|
| 美股（隔夜） | 道指 / 纳指 / 标普 | 三大指数涨跌幅 |
| | 纳指 | 科技代理，映射 A股科技 / 半导体 |
| | 费城半导体 SOX | 直接映射 A股半导体设备 / CPO |
| | 纳斯达克中国金龙 | 中概情绪，映射 A股情绪面 / 外资偏好 |
| | VIX | 风险偏好（反向） |
| 韩股（盘中） | KOSPI / KOSDAQ | 涨跌幅（KOSDAQ 更贴近 A股题材） |
| | 三星电子 / SK海力士 | 半导体双雄，映射 A股存储 / 半导体 |

**关键字段**：
- **外盘情绪温度**：美股 / 韩股各合成一个 0-100 温度（MVP 规则加权：涨跌 + 波动 + 板块广度，后期 AI 校准），与 A股双维度温度口径一致
- **较昨日 + 近5日轨迹**：外盘也遵循"时间维度一等公民"，不孤立给一帧
- **外盘背离**：美股 × 韩股方向相反时提示 ⚠，并与 A股短线情绪叠加成三层背离
- **配色**：外盘卡片沿用 A股红涨绿跌配色，统一标注涨跌箭头 + 正负号，避免同屏两种色义打架

**联动**：外盘情绪进入「动态过程」一句话综合（"外盘 → A股"）；板块映射——美股半导体强 → 看 A股半导体设备 / CPO 是否跟，落到涨停梯队 / 市场聚焦解读。

#### 情绪演化主轴（大盘情绪的时间轨迹）

这是全页的"心脏"：把 A股大盘情绪（短线 × 趋势）画成**近 N 日的时间序列**，今日是终点而非孤点。

**短线情绪**（温度 0-100，五档：冰点 / 低迷 / 中性 / 活跃 / 过热）：

- 加权：空间高度 25% + 晋级率 20% + 炸板率（反向）20% + 昨涨停表现 20% + 涨停家数 15%
- 五阶段周期（冰点 → 启动 → 发酵 → 高潮 → 退潮）归属此维度；轨迹图会标注"今天是退潮第 2 天"

| 阶段 | 识别特征（初版规则） | 操作提示（与原则库联动） |
|------|---------------------|------------------------|
| 冰点 | 涨停 <20 且跌停 ≥ 涨停，高度 ≤2 | 空仓观察，记录潜在主线 |
| 启动 | 首板 >30，出现 3 板 | 小仓位试错，低吸为主 |
| 发酵 | 梯队完整（2/3/4 板齐），炸板率 <20% | 可参与主线中军，忌追高位板 |
| 高潮 | 温度 >80，高度 ≥6 板加速 | 兑现为主，不新开仓（不追高） |
| 退潮 | 高位板断板，炸板率 >40%，昨涨停转负 | 控制仓位，等下一个冰点 |

| 短线指标 | 口径 | 演化展示 |
|----------|------|----------|
| 空间高度 | 当日最高连板数（含断板注记） | 近5日高度折线（6→4→3…） |
| 晋级率 | 今日 2 板数 ÷ 昨日首板数 | 近5日折线 |
| 炸板率 | 炸板数 ÷（炸板数 + 收盘涨停数） | 近5日折线（反向看） |
| 昨涨停表现 | 昨日涨停股今日均涨 | 近5日折线（正负分色） |
| 昨连板表现 | 昨日连板股今日均涨 | 近5日折线 |
| 大面数 | 昨日涨停今日跌 >5% 家数 | 近5日柱状 |
| 涨停 / 跌停 | 含 ST，剔除新股上市首日 | 近5日柱状 |

**趋势情绪**（温度 0-100，五档：空头 / 弱势 / 中性 / 强势 / 过热）：

- 加权：指数均线结构 30% + 市场宽度 25% + 量能趋势 20% + 资金 15% + 20 日强度 10%

| 趋势指标 | 口径 | 演化展示 |
|----------|------|----------|
| 指数均线结构 | 上证 / 沪深300 / 创业板 vs MA20 / MA60 | 各指数"站上/跌破"状态时间条 |
| 涨跌家数 | 全市场上涨 / 下跌占比 | 近5日折线 |
| 新高 / 新低 | 创 60 日新高 / 新低家数差 | 近5日差值柱状 |
| 成交额趋势 | 两市合计，5 日趋势 | 近5日柱状 + 放量/缩量标记 |
| 两融余额 | 融资余额日变化 | 近5日柱状 |
| 主力净流入 | 大单净额（可选） | 近5日柱状（红绿） |

**背离提示**：短线与趋势方向相反时显示 ⚠，并叠加「背离持续第 N 天」——背离本身也是一个演化过程，第 1 天与第 4 天含义不同。

**背景如何作用于后续模块**（本页的叙事主线）：

| 后续模块 | 背景作用方式 |
|----------|-------------|
| 涨停梯队（6.4） | 梯队是短线情绪的结构化呈现：断板 / 晋级数据实时反哺短线温度，并叠加"高度下降轨迹" |
| 热点事件（6.5） | AI 解读带背景标签 + 生命周期：如「利好 × 退潮期 → 利好钝化」「利好 × 发酵期 → 主线共振」 |
| 焦点个股（6.5） | 「为什么热」结合背景与上榜连续天数：高潮期连续上榜 = 最后一棒风险；冰点期首次上榜 = 新周期候选 |
| 今日动态过程 | AI 一句话综合，作为录入预期 Step 3 大盘推理的参考起点（结论仍需自己写） |

> 温度计算 MVP 用规则加权，后期 AI 校准；阶段与档位提示引用用户自己的原则库条目（如「不追乖离 >5%」），让市场语境与个人纪律挂钩，而不是给出通用荐股话术。

### 6.5 模块四：市场聚焦演化

三档聚焦：**月聚焦**（本月主线 + 龙头 + 风格）· **周聚焦**（本周，内嵌前一周时间轴回溯）· **明日重点聚焦**（前瞻）。每一档都用生命周期标签串起持续性，且周聚焦可点选回看前一周内任意一天的个股与事件。

```

```

**三档内容定义**：

| 档位 | 时间范围 | 核心内容 |
|------|---------|---------|
| **月聚焦** | 近 20 日（本月） | 月度主线题材（事件线月级聚合）· 月度龙头榜（月涨幅前列）· 月度风格（大小盘 / 成长价值 / 资金流向） |
| **周聚焦** | 近 5 日（本周） | 本周主线事件线 · 周度焦点个股（连续上榜）· 周度热点板块 · **内嵌 7 天时间轴**（回看每一天） |
| **明日重点聚焦** | 前瞻（明日） | 明日关键事件表（财报 / 解禁 / 会议 / 数据）· 明日关注板块（今日发酵延续 + 退潮风险）· 明日关注个股（晋级候选 / 断板风险）· AI 前瞻一句话 |

**关键点**：
- 「明日重点聚焦」是**前瞻视图**（指向明日），与「月/周聚焦」的**回顾视图**方向相反，单独一档，不含时间轴
- 「周聚焦」的 **7 天时间轴**满足「回看前一周内的时间与个股」：点选某天即全局回溯（事件 / 个股 / 板块三列一起切换，与 6.2 主轴点选联动一致）
- 生命周期标签（🆕首发 / 🔥发酵 / 🧊退潮 / 已了结）在三档内继续沿用，仅时间尺度不同

**事件卡片字段**（周聚焦 · 热点事件 Tab，在原字段基础上新增生命周期）：
- 时间 · 类别（政策 / 产业 / 公司 / 海外 / 资金 / 传闻）· 多空标记（🔴 利好 / 🟢 利空 / ⚪ 中性，沿用 A股配色）· 影响板块 · 标题 · AI 一句话解读 · **生命周期**（🆕 今日首发 / 🔥 持续发酵第N天 / 🧊 热度退潮第N天 / 已了结）· **背景解读**（结合 6.3 双维度）· 关联个股（带今日涨幅）· [＋引用]
- 事件时间轴可**上翻**看前几日的事件，同一主题的事件归并成一条"事件线"（如「固态电池」从首发到发酵的完整脉络）

**焦点个股 Tab**（周聚焦内）：排序切换（成交额 / 换手率 / 龙虎榜 / 上榜天数），每行附「为什么热」与「上榜轨迹」：

  为什么热：三日两现机构专用席位买入，叠加热点空间板带动
6007XX  XX股份  +10.0%  成交 38亿  换手 27%  [算力租赁]  连续上榜 2 天 →
3004XX  XX能源  +20.0%  成交 65亿  换手 33%  [固态电池]  今日新进 🆕
6880XX  XX设备  -3.2%   成交 12亿  换手 8%   [半导体设备] 昨日上榜今日掉出 ↓
```

- **上榜轨迹**：连续上榜 N 天（↑ 升温 / → 持平 / ↓ 降温）· 🆕 今日新进 · ↓ 今日掉出，让"钱在哪"也变成一条流动的过程

**热点板块 Tab**（周聚焦内）：在板块表格外新增「近5日板内涨停家数」迷你柱状，看板块热度的起落：

```

### 6.7 数据与刷新

- **盘中**：涨停 / 炸板 / 跌停池分钟级轮询（免费源限流，间隔可配置）；事件流 5 分钟
- **收盘**：15:30 生成每日快照并存档（JSON），历史快照累积成**情绪时间序列**，是「近 N 日轨迹 / 生命周期 / 上榜轨迹」的数据底座
- **免费数据源**：AkShare 涨停池 / 炸板池 / 跌停池 / 昨日涨停表现；涨跌家数与成交额来自市场总览接口
- **外盘数据**：美股隔夜收盘定格数据早盘一次性加载（盘中补纳指期货 / 美债收益率）；韩股 8:00-15:30 实时（KOSPI / KOSDAQ 指数 + 三星 / SK海力士）
- **降级**：数据源失败时模块级占位「行情源暂不可用」，不影响其他模块

**口径补充（v0.4）**：
- **量能**：两市成交额，放量 / 平量 / 缩量以「较 5 日均值 ±15%」为阈值
- **龙头识别（规则初版）**：板块内最高连板或封单最强为该板块龙头；全场最高连板为空间龙头；「带领板块上涨」= 涨停后带动同板块 ≥3 只跟风涨停
- **涨停时间分桶**：一字板 9:25 / 早盘 9:30-10:30 / 上午 10:30-11:30 / 午后 13:00-14:00 / 尾盘 14:00-15:00，按首封时间
- **三档聚焦时间窗**：月聚焦近 20 日 · 周聚焦近 5 日（时间轴可回看近 7 个自然日 / 约 5 个交易日）· 明日重点聚焦指向下一交易日
- **外盘情绪温度**：美股 / 韩股各合成 0-100 温度，MVP 规则加权（涨跌 + 波动 + 板块广度），后期 AI 校准；配色沿用 A股红涨绿跌 + 涨跌箭头 / 正负号

## 七、关键组件设计

## 八、交互与信息层级规则

### 8.1 录入流程节奏

- 心理快照（Step 1）：**不可跳过**，但尽量快（单屏，约10个点击）
- 大盘预期（Step 3）：**必填**，信念假设建议但不强制（至少1条）
- 个股预期（Step 4）：完全可选，但有则必须填写止损和判断理由

### 8.2 复盘提醒逻辑

- 收盘后自动评分完成 → 列表卡片出现「待复盘」黄色标记
- 用户下次打开 `/expectations` 时，未复盘的条目置顶展示
- 超过3天未复盘的条目，显示柔和的提示文案（不强制，不弹窗）

### 8.3 成长数据可见性

- 成长仪表盘指标：至少有 **7天**数据才开始展示，否则显示"再记录 X 天后解锁"
- 偏差画像：至少 **5次**偏差标注后显示分布图
- 方法论文档：至少 **30天**数据后系统自动填充，之前为引导空状态
