## 一、大盘情绪页阶段感知读数（已实现）

`MarketSentimentService.get_overview` 按 A 股交易阶段（`src/core/trading_calendar.py`，XSHG 日历）自动决定数据来源，`realtime=true` 保留显式强制实时。

| 阶段（market_phase） | 数据来源 | 说明 |
| --- | --- | --- |
| intraday / lunch_break / closing_auction | 读库 + 实时块 | `realtime.indices` + `realtime.market_stats`；**60s TTL 缓存**（`_REALTIME_TTL_SECONDS`，锁内拉取防并发惊群），失败记 `degraded: ['realtime']` |
| postmarket（>= 15:05 本地） | 读库 + 后台补采 | 当日快照缺失/不完整时起守护线程 `collect_daily_snapshot(trade_date=归属交易日)`，按日幂等（内存状态 + `is_complete` 守卫）；采集中记 `degraded: ['snapshot_collecting']` |
| postmarket（15:00-15:05 宽限窗口） | 纯读库 | 等涨跌停池定型，不触发采集 |
| premarket / non_trading / unknown | 纯读库 | 零外部请求；UNKNOWN（exchange-calendars 缺包）fail-open 为纯读库，显式 `realtime=true` 仍可用 |

- 快照归属交易日：`_resolve_snapshot_trade_date()` —— 交易日取当日，节假日取最近已收盘交易日（修复此前 `date.today()` 在节假日把 09-24 数据记成 09-25 的问题）。
- 快照表新增 `sh_close` / `sh_chg_pct`（上证指数收盘点位/涨跌幅），SQLite 旧库启动时 `ALTER TABLE` 自动补列（重复列容错）。
- 前端：盘中三态启动 60s 轮询只刷 overview（页面不可见时暂停，可见时立即刷新）；指数行情卡优先 `realtime.indices`（`实时` 标注），否则用快照指数字段合成（`收盘` 标注）；页头按 `market_phase` 显示阶段标签。

## 二、数据源边界实测（2026-09）

| 通道 | 实测结论 |
| --- | --- |
| 东财 push2his（akshare `stock_zh_index_daily_em`） | 指数日线含 `amount`（元），沪市总额口径与实时"上证指数"成交额一致；**限流时持续 RemoteDisconnected**（本轮回填期间断连超 20 分钟），需依赖 fallback |
| 新浪 `stock_zh_index_daily` / 腾讯 `stock_zh_index_daily_tx` | 指数日线**只有 volume 无成交额**；作为 fallback 命中时 `sh_amount`/`total_amount` 会缺失 |
| Tushare `index_daily`（`000001.SH`） | 含 `amount`（**千元口径**，÷1e5 = 亿元）；免费 token **限频 1 次/小时**，仅适合低频补齐不适合实时 |
| akshare 涨停/跌停/炸板池接口 | 原生支持 `date` 参数（`%Y%m%d`），可按历史日期回采 |
| 涨跌家数（up/down/flat）与外盘 | 无免费历史源，回填行置空 → `sentiment_st`/`sentiment_trend` 为 None |

## 三、历史回填口径（`backfill_recent_snapshots`）

- 交易日由日历往回推；跳过"快照齐全（`is_complete=1` 且 `total_amount` 非空）"的日期 → 数据源限流致量能缺失时**重跑同一命令可自动补齐**。
- 可得字段：指数点位/涨跌（日线链路）、`sh_amount`/`sz_amount`（上证指数/深证综指日线，沪市缺失时 tushare 补齐）、三类池/梯队/炸板率（按日期拉取）。
- 置空字段：涨跌家数、外盘、情绪温度、主力/北向、60 日新高新低。
