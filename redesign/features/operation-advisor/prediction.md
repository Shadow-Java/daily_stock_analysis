# 明日走势预测（prediction）设计文档

> 版本: v0.1 | 日期: 2026-09-26 | 状态: 草稿（待评审，未开工）
> 回答的问题：每天收盘后，系统对「明天会怎么走」给出**概率化、可证伪、可对账**的预测——市场层（阶段转移）、板块层（TopN 延续性）、个股层（衔接 design.md §3.8 剧本），次日自动对账验证，长期积累可查的预测战绩。
> 定位：operation-advisor 的预测子层。design.md §3.8 已有「个股层明日预期 + 竞价预案」，本文档将其升级为完整三层预测体系 + 验证闭环；两处冲突时以本文档为准。

---

## 一、预测观（先划清能做什么、不做什么）

**核心立场：短期走势不可被确定性预测；可被预测的是「条件概率的偏移」。**

| 原则 | 含义 |
|---|---|
| 概率化 | 不说「明天涨」，说「明天延续强势概率约 60%，转分歧 30%，转弱 10%」 |
| 可证伪 | 每条预测必带「什么信号出现说明我错了」（证伪条件） |
| 可对账 | 每日预测落库快照，次日自动判定命中/未命中，战绩如实展示（含打脸记录） |
| 服务决策 | 预测直接对接仓位（design.md §7.1）与打法路由（scoring §2.4）——不改变动作的预测没有价值 |
| 合规 | 不做点位/收益承诺；输出标「AI 概率估计，仅供参考，不构成投资建议」 |

**明确不做**：
- ❌ 指数点位预测（「明天上证 3250 点」）——不可行且不合规；
- ❌ 无对账的预测（没有验证闭环的预测就是玄学）；
- ❌ 盘中高频预测——本功能保持每日盘后视角，盘中属阶段 3 竞价联动。

## 二、预测对象分层（预测什么）

| 层 | 对象 | 输出 | 与现有设计的衔接 |
|---|---|---|---|
| L1 市场层 | 明日情绪阶段转移 | 五阶段转移概率分布（如 主升 50%/高潮 30%/退潮 20%）+ 三剧本 + 观察点 | scoring §2.2 状态机的出边即候选转移边 |
| L2 指数层 | 沪深300 明日区间 | **仅作 L1 剧本附注**（不建独立模型） | 锚定点（anchor-points）上下沿作参考位 |
| L3 板块层 | 当日板块 TopN 明日延续性 | 每板块延续概率 + 分歧信号 | `advisor_sector_score`（scoring §3.5）已产 TopN |
| L4 个股层 | 池内股明日剧本 | 四情景表 + 情景概率 + 次日对账 | design.md §3.8 已有骨架，本文档补概率与对账 |

优先级：**L1 与 L3 是新增重点**（用户最关心的「明天行情怎么走」）；L2 刻意降级（样本与合规双约束）；L4 复用为主。

## 三、预测引擎：三个信息源 + 融合

### 3.1 规则外推（阶段 1 主力，零样本可用）

利用情绪的**惯性与边际变化**：阶段很少一日反转，转折前通常有连续证据。

转移概率 = 先验矩阵 + 证据调制：

```
对今日阶段 S 的每条合法出边 e（来自 scoring §2.3 状态机）：
  score(e) = prior(S→e) + Σ 证据_i(e)
  P(e) = normalize(score)，单边单日调整限幅 ≤20pp（防证据把概率推向极端）
```

**经验先验矩阵初值**（待评审，§4.1）：

| 今日阶段 | 出边 → 先验概率 |
|---|---|
| 冰点 | 冰点 45% / 回暖 55%（超跌反抽是常态） |
| 回暖 | 回暖 45% / 主升 40% / 退潮 15% |
| 主升 | 主升 50% / 高潮 30% / 退潮 20% |
| 高潮 | 高潮 35% / 退潮 45% / 主升 20% |
| 退潮 | 退潮 45% / 回暖 30% / 冰点 25% |

**边际证据表**（每项对候选出边 ± 支持分，全部来自已有快照，零新增采集）：

| 证据（当日 vs 前一日） | 指向 |
|---|---|
| 晋级率 P 环比升 ≥5pp | 延续/升级边 + |
| 炸板率 B 环比升 ≥5pp | 降级/退潮边 + |
| 连板高度 H 变化 +1 | 延续/升级边 + |
| 空间板断板（anchor-points 龙头断板事件） | 退潮边 ++ |
| 成交额环比缩 >10% 且指数收涨 | 高潮/分歧边 + |
| 跌停家数 ≥ 涨停家数一半 | 冰点边 + |
| 外盘昨夜剧变（overseas_summary，阶段 2 再启用） | 视方向 + |

### 3.2 历史基率（样本积累后逐步接管）

统计「与今日特征相似的历史日，次日实际怎么走」，替换经验先验：

- 特征向量：`E, ΔE, L, ΔL, B, P, H, M, 成交额环比`（全部已有）；
- 相似检索：同阶段内按加权距离取最近 K=20 个历史日，次日实际转移分布即基率；
- **启用门槛：同阶段样本 ≥60 日才启用**，此前保持规则先验——避免小样本噪音；
- 数据源：`market_daily_snapshot` 历史行（每日自然积累，约 3 个月可启用 L1）。

### 3.3 LLM 研判（阶段 2，白名单 + 限幅）

- 输入：L1 候选出边与规则概率 + 边际证据 + 近期 focus 事件 + 外盘摘要；
- LLM 允许：在规则产出的剧本集合内**调整概率（单边 ±15pp）**、必须给出 1-2 句理由；
- LLM 禁止：发明新剧本、直接给方向论断、修改阶段判定；
- 失败降级：直接用规则概率，不影响出报告。

### 3.4 融合与权重演进

```
P_final = normalize( w_rule×P_规则 + w_hist×P_基率 + w_llm×P_llm )
阶段 1: w_rule=1.0, w_hist=0, w_llm=0
阶段 2: w_rule=0.6, w_hist=0.2, w_llm=0.2
阶段 3: 按对账战绩自动校准（§7），某信息源长期拖后腿则降权
```

## 四、L1 市场层输出形式：「明日市场剧本卡」

每日一条，三剧本 + 观察点，全部概率合计 100%，每剧本必带证伪条件：

```
明日预测（09-26 收盘后生成 | 今日阶段：主升 | 置信度：中）
① 转移概率：主升 50% / 高潮 30% / 退潮 20%
② 基准剧本（50%）：强势延续——晋级率守 30%+，涨停 70+ 家
   → 动作：打法维持，仓位维持区间中值
   → 证伪：明日炸板率 >25% 且晋级率 <25%
③ 分歧剧本（30%）：冲高分歧——空间板尾盘炸板、高潮特征出现
   → 动作：兑现 1/3，打板只留空间板
   → 证伪：明日晋级率不降反升
④ 转弱剧本（20%）：龙头断板 + 亏钱效应扩散
   → 动作：仓位降至区间下沿，禁追高打板
⑤ 明日观察点（开盘 30 分钟内可判定）：
   - 昨日涨停股前 30 分钟溢价 ≥ +1% → 基准剧本确认
   - 竞价晋级率 < 25% → 转分歧预警
   - 市场空间板竞价 < +5% 或开盘被砸 → 转弱预警
```

设计要点：**观察点把「预测」变成「明早的行动清单」**——与 §3.8 竞价预案同一哲学：不赌对错，只给「出现什么就做什么」。

## 五、L3 板块延续性预测

对当日板块 TopN（≤5 个）逐个预测「明日延续」：

**延续的定义（开放问题 §11-2，建议 A）**：次日板块仍在涨幅榜 Top10，或板块内再出现 ≥2 家涨停。

因子（全部已有数据）：

| 因子 | 方向 | 说明 |
|---|---|---|
| 板块连涨天数 | + | 1-2 天延续概率高，≥4 天衰减（透支） |
| 板块内涨停家数趋势 | + | 今日较昨日增 → +；减 → − |
| 龙头晋级 | + | 板块最高板今日晋级成功 → 强延续；断板 → 分歧 |
| 题材催化新鲜度 | + | focus 事件距今 ≤2 天 +；>5 天 − |
| 板块成交额占比环比 | ± | 放量延续 +；缩量 lone dragon − |

**基率可立即启用**：`get_sector_history` 已有板块区间行情，阶段 1 即可一次性回溯统计「当日涨幅榜 Top10 → 次日仍 Top10 的历史频率 / 次日涨幅分布」——板块层是三层中**样本最多、最快能出真实基率**的层，作为整个基率体系的先行试点。

输出：每板块「延续概率 + 分歧信号一句话」（如「算力 70% 延续；若龙头明日断板则分歧」）。

## 六、L4 个股层：衔接与升级 §3.8

- §3.8 四情景表已落地「剧本 + 动作」，本层补两点：
  1. **情景概率**：每情景标概率（阶段 1 经验值，如低吸股 B+C 合计 70%；阶段 2 用池内历史竞价命中率替换）；
  2. **次日对账**：实际竞价涨跌幅落入哪个情景区间 → 回填 hit（§7）。
- 不改变 §3.8 的执行语义（用户 9:25 人工对照 / 阶段 3 自动比对）。

## 七、验证闭环（本设计的灵魂）

### 7.1 预测落库（生成时点快照，事后不可改）

`advisor_prediction`：`id, trade_date, level(market/sector/stock), target_code, scenarios_json[{name, prob, condition, action, falsifier}], watch_points_json, confidence, engine_version, created_at`。

### 7.2 次日自动对账（advisor 流水线尾部一步，确定性规则）

| 层 | 命中判定 | 概率损失 |
|---|---|---|
| L1 | 次日用 scoring §2.2 状态机重判实际阶段，实际转移边 vs 预测分布 | `hit = (概率最高边 == 实际边)`；`brier = Σ_e (p_e − 1[e=实际])²` |
| L3 | 按延续定义判定，hit = 预测延续且实际延续（或预测分歧且实际分歧） | 同上（二元） |
| L4 | 实际竞价涨跌幅落入哪情景区间 → 该情景为实际 | 同上 |

### 7.3 战绩展示（页面「预测战绩」卡）

- 近 30 日分层命中率、Brier 均值、最长连对/连错、打脸记录列表；
- 对照基线：L1 三边随机 = 33%，L3/L4 二元 = 50%；
- **反向指标自检**：某预测类型命中率持续低于基线 → 自动降权（§3.4）并在页面标注「该层预测暂不可信」——宁可少说，不可瞎说。

## 八、数据模型（新增 2 表）

| 表 | 用途 | 关键字段 |
|---|---|---|
| `advisor_prediction` | 每日预测快照 | 如 §7.1 |
| `advisor_prediction_result` | 次日对账结果 | prediction_id, actual(实际情景/转移边), hit, brier, checked_at |

不改动 advisor 既有 6 表；`market_daily_snapshot` 历史行即基率样本库。

## 九、分阶段落地

| 阶段 | 内容 | 说明 |
|---|---|---|
| 阶段 1（MVP） | L1 规则先验+证据调制；L3 板块基率一次性回溯 + 规则预测；市场剧本卡 + 观察点；对账落库（hit/brier） | 零新增实时采集；板块基率用 get_sector_history 离线回溯 |
| 阶段 2 | LLM 概率研判（限幅）；L2 指数区间基率附注；L4 情景概率化；战绩页；外盘证据启用 | L1 基率约 3 个月后样本达标自动启用 |
| 阶段 3 | 权重按战绩自动校准；预测类型自动升降权；与竞价实时比对推送联动（§3.8 阶段 3） | 校准参数仍集中管理（scoring §五） |

## 十、优化建议

1. **对账闭环从阶段 1 就做**——每晚一次确定性计算，成本极低，却是整个预测体系可信度的唯一来源；先于 LLM/基率存在；
2. **基率先行板块层**：样本最多、见效最快，作为基率管线试点，跑通后再推广 L1/L4；
3. **指数点位坚决不做**：L2 只作剧本附注，等阶段 2 基率自动生成，避免过度承诺；
4. **LLM 只调概率不发明剧本**（白名单 = 规则产出集合）+ 限幅 ±15pp + 强制给理由，防 LLM 过度自信污染分布；
5. **预测密度克制**：市场 1 条/日 + 板块 ≤5 + 个股仅池内（≤30）——预测越多命中率越稀释、用户越看不过来；
6. **如实展示打脸**：战绩页包含错误预测列表，长期可信度反而来自承认错误；
7. **观察点设计为「开盘 30 分钟内可判定」**：把预测变成次日早晨的行动清单，与竞价预案哲学一致，避免用户盘中盯盘焦虑。
