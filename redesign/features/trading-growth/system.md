## 一、系统建设目的

### 1.1 核心命题

> **打造属于自己的交易系统，而非依赖外部信号。**

市场上的工具、AI 信号、分析师观点，都是外部输入。真正决定长期盈亏的，是你在不确定性中**如何思考、如何决策、如何执行**。这个系统的建设目的，不是帮你预测市场，而是帮你认识自己——认识自己的判断逻辑、情绪驱动、执行习惯和认知盲区。

**往内求**的本质是：把每一次交易当作一次自我实验，用数据和反思替代感觉和记忆，最终沉淀出**只属于你的、可持续迭代的交易方法论**。

### 1.2 系统愿景

```
外部工具（AI信号/新闻/数据）
        │
        ▼  提供素材，不替代判断
┌───────────────────────────────┐
│         你的交易系统           │
│                               │
│  ┌─────────┐  ┌────────────┐  │
│  │ 信念体系 │  │ 交易原则库 │  │
│  └────┬────┘  └─────┬──────┘  │
│       │             │         │
│  ┌────▼─────────────▼──────┐  │
│  │     每日预期 & 判断过程   │  │
│  └────────────┬────────────┘  │
│               │               │
│  ┌────────────▼────────────┐  │
│  │   执行 & 交割单真实记录  │  │
│  └────────────┬────────────┘  │
│               │               │
│  ┌────────────▼────────────┐  │
│  │   复盘 & 模式识别        │  │
│  └────────────┬────────────┘  │
│               │               │
│  ┌────────────▼────────────┐  │
│  │   成长仪表盘 & 迭代      │  │
│  └─────────────────────────┘  │
└───────────────────────────────┘
        │
        ▼  输出：更稳定、更自知的你
```

### 1.3 这个系统不是什么

- 不是选股工具
- 不是 AI 代替你判断的工具
- 不是给你正确答案的工具
- 不是考核你赚了多少钱的工具

**它是一面镜子**：完整、诚实地映照你的思维过程、行为习惯和成长轨迹。

### 1.4 长期目标

| 阶段 | 目标 | 标志 |
|------|------|------|
| 第1-3个月 | 建立记录习惯，识别主要认知偏差 | 能说出自己的3个高频偏差 |
| 第3-6个月 | 验证并打磨个人交易原则 | 原则违规率 < 20% |
| 第6-12个月 | 稳定的预期质量，形成方法论 | 推理质量分均值 > 3.5/5 |
| 1年以上 | 拥有可文档化的个人交易系统 | 能用一页纸写清楚自己的交易逻辑 |

## 二、往内求：核心功能设计

### 2.1 录入前置心理快照

**目的**：把无意识的情绪状态变成可测量的数据。

每次录入预期前，强制完成一个 60 秒的自我检查：

```
┌────────────────────────────────────────────────────┐
│  录入预期前：先了解此刻的自己                       │
├────────────────────────────────────────────────────┤
│                                                    │
│  1. 当前情绪状态                                   │
│     极度恐惧 ◁────────●────────▷ 极度贪婪          │
│                    [5]                             │
│                                                    │
│  2. 这次判断的主要驱动是？（可多选）                │
│     ☑ 数据推理   ☐ 市场感觉                        │
│     ☐ 消息面     ☐ 跟随他人观点                    │
│     ☐ 仓位压力   ☐ 情绪冲动                        │
│                                                    │
│  3. 今天用于研究的时间？                           │
│     ☐ <30分钟   ☑ 30-90分钟   ☐ >90分钟           │
│                                                    │
│  4. 近期是否有以下干扰？（可多选）                  │
│     ☐ 连续亏损状态   ☐ 连续盈利状态（过度自信风险）│
│     ☐ 仓位集中焦虑   ☐ 外部舆论压力                │
│                                                    │
│                          [继续录入预期 →]          │
└────────────────────────────────────────────────────┘
```

**数据价值**：
- 长期积累后，可做"情绪状态 × 预期准确率"相关性分析
- 识别个人的高表现心理区间（例如：情绪指数 4-6 区间时准确率最高）
- 主动发现"冲动交易"模式

### 2.2 信念假设显式化

**目的**：把直觉和感觉转化为可检验的命题，区分"判断"和"猜测"。

在个股预期中，每条判断必须填写**支撑该判断的核心假设**（1-3条）：

```
我的假设（收盘后系统会追问这些假设是否成立）：
┌──────────────────────────────────────────────────────┐
│ 假设1: 美联储本次不加息，市场流动性保持宽松           │
│ 假设2: 该股本周成交量持续放大，筹码换手完成           │
│ 假设3: 同行业龙头已企稳，板块联动效应会传导          │
└──────────────────────────────────────────────────────┘
```

**收盘后追问**（系统在自我复盘环节逐条提问）：
- 假设1 是否成立？ [成立 / 不成立 / 无法判断]
- 假设2 是否成立？...

**四象限分析**（显示在详情页）：

```
              假设成立
                 │
    ┌────────────┼────────────┐
    │            │            │
结果│  假设对了  │  假设对了  │
错误│  但结果错  │  且结果对  │  结果
    │（执行问题）│（判断扎实）│  正确
    ├────────────┼────────────┤
    │  假设错了  │  假设错了  │
    │  且结果错  │  但结果对  │
    │（判断失败）│（运气成分）│
    └────────────┼────────────┘
                 │
              假设不成立
```

这是比简单对错更有价值的复盘——**运气型正确**和**逻辑型正确**需要被区分开来。

---

### 2.3 个人交易原则库

**目的**：把隐性的交易规则显式化，通过数据追踪知行合一的程度。

#### 原则管理页

用户可自由添加、修改、停用原则：

```
我的交易原则库

  #1  ✅ 活跃  不在周五下午开新仓
      理由: 无法管理周末消息面风险
      创建: 2026-07-12  违规率: 23% (6/26次)

  #2  ✅ 活跃  预期信心低于3星时只观察不操作
      理由: 模糊判断不应该有仓位
      创建: 2026-08-01  违规率: 8% (2/25次)

  #3  ✅ 活跃  单只个股仓位不超过总资金20%
      理由: 控制集中度风险
      创建: 2026-06-15  违规率: 0%

  #4  ⚠ 活跃  止损位设定后不移动
      理由: 防止越亏越拿
      创建: 2026-07-01  违规率: 61% (14/23次)  ← 高违规警示

  [+ 添加原则]
```

#### 录入时的原则检查

提交预期时，系统自动匹配可能违反的原则并提示：

```
⚠ 检测到可能违反原则 #1：
  你计划在周五买入 600519，但你的原则 #1 规定"不在周五下午开新仓"

  选择：
  ◉ 我知道，有意识地例外，原因：_______________
  ○ 调整操作计划，遵守原则
```

**有意识地破例**比无意识违规更有价值——记录的是你的主动决策，而非疏漏。

### 2.4 认知偏差识别体系

**目的**：给思维盲区命名，才能开始管理它。

#### Agent 偏差标注

Agent 在评价预期时，对识别到的偏差进行精确标注：

| 偏差类型 | 识别特征示例 | 处置建议 |
|---------|------------|---------|
| **锚定偏差** | "等回到XX价再说" / 判断围绕某历史价展开 | 重新从当前基本面出发定价 |
| **确认偏差** | 理由全部支持自己方向，无反例考虑 | 主动写出反对观点 |
| **近因效应** | "连续3天涨了，明天应该继续" | 检查均值回归概率 |
| **损失厌恶** | 亏损股"等回来"，频繁调整止损位 | 对照入场逻辑，非价格决策 |
| **过度自信** | 信心5星但历史准确率 < 50% | 强制降低信心等级 |
| **FOMO** | 理由中包含"怕踏空" / "别人都在买" | 检查是否有独立逻辑支撑 |
| **处置效应** | 赢家卖太快 / 输家持太久 | 用假设"今天新建仓"重新判断 |
| **叙事谬误** | 用一个故事解释所有数据 | 拆解故事，找出可证伪的假设 |

#### 个人偏差画像（统计页）

```
你的高频认知偏差（近90天）

确认偏差  ████████████████  32次  (38%)  ← 首要关注
近因效应  ██████████        20次  (24%)
损失厌恶  ████████          16次  (19%)
FOMO      ██████            12次  (14%)
过度自信  ███               6次   (7%)

趋势：确认偏差 近30天出现 8次，较上月下降 40% ✅
```

### 2.5 Socratic Agent（苏格拉底追问模式）

**目的**：在提交前主动挑战自己的判断，把"感觉对"转化为"经得起追问"。

用户填写完预期后，可选择开启 Socratic 模式。Agent 不评判对错，只提出问题：

```
🤔 我有几个问题，不需要回答我，但请在提交前自己想清楚：

关于你的大盘判断"明日上涨"：
  → 你的判断主要来自技术面还是基本面？两者是否一致？
  → 如果今晚美股大跌，你的判断会改变吗？你的计划有考虑这个情景吗？

关于 600519 的买入计划：
  → 你上一次在类似位置买入的结果是什么？
  → 如果你明天不看盘，这笔交易你还会做吗？
  → 你的止损在哪里？突破止损后你会执行吗？（根据你的历史，原则#4违规率61%）

这些问题没有标准答案。如果你想清楚了，[提交预期]。
```

**关键设计原则**：Socratic Agent 不给答案，只提问。用户自己想清楚，比 Agent 告诉他"你错了"更有内化价值。

### 2.6 反事实复盘（Counterfactual Analysis）

**目的**：区分"判断问题"、"计划问题"、"执行问题"，不把所有失败混为一谈。

收盘后，系统除了常规评分，还自动计算3个反事实场景：

```
2026-09-19 复盘 — 反事实分析

你的实际结果：      -1.2%（预期买入但当天犹豫未执行）

反事实 A：如果完全按计划执行
          假设按计划以开盘价买入...    结果 +2.3% ✅
          → 结论：这次是执行问题，不是判断问题

反事实 B：如果采纳了 AI DecisionSignal
          AI 当日建议：减仓，目标价下移...  结果 +0.8%
          → 结论：你的判断优于 AI 信号（本次）

反事实 C：如果什么都不做（持有原仓位）
          原仓位昨日收盘到今日收盘变化... -0.3%
          → 结论：你的预期方向带来了正向超额，但执行失误
```

这套分析让用户清楚看到：**问题出在哪一环**——是判断错了，还是计划有漏洞，还是执行没跟上。

## 三、交割单复盘系统

### 3.1 设计目的

**预期记录**是主观的——你计划做什么。
**交割单**是客观的——你实际做了什么。

两者之间的差距，是成长最密集的地方。

交割单复盘的目标：
1. 真实还原每笔交易的执行情况（时间、价格、成本）
2. 将真实交易与预期计划自动匹配，量化执行偏差
3. 从交割单中提取客观的盈亏归因，剔除记忆偏差

### 3.2 交割单导入

支持多种导入方式（不同券商格式标准不一）：

#### 支持格式

| 券商 | 格式 | 字段 |
|------|------|------|
| 通用 CSV | 用户映射字段 | 灵活适配 |
| 同花顺导出 | `.xls` / `.xlsx` | 自动解析 |
| 东方财富 | `.csv` | 自动解析 |
| 手动录入 | Web 表单 | 单笔填写 |

#### 导入数据结构

```
TradeRecord（单笔成交记录）
├── id                UUID
├── import_batch_id   批次 ID（同一次导入归组）
├── trade_date        Date，交易日期
├── trade_time        Time | null，成交时间（精确到分钟）
├── stock_code        str
├── stock_name        str
├── direction         Enum: buy / sell
├── quantity          int，成交数量（股）
├── price             float，成交均价
├── amount            float，成交金额
├── commission        float | null，手续费
├── tax               float | null，印花税/过户费
├── net_amount        float，实际净额（含费用）
├── source            Enum: import_csv / import_excel / manual
└── raw_row           JSON | null，原始导入行（用于 debug）
```

### 3.3 交割单复盘核心功能

#### 3.3.1 预期 × 执行匹配

系统自动将交割单记录与预期计划进行匹配（按日期 + 股票代码）：

```
2026-09-19 执行对比

╔═══════════════════════════════════════════════════════════╗
║  600519 贵州茅台                                          ║
╠═══════════════════╦═══════════════════════════════════════╣
║  计划（预期记录） ║  实际（交割单）                        ║
╠═══════════════════╬═══════════════════════════════════════╣
║  操作: 买入       ║  操作: 买入 ✅                        ║
║  计划时机: 开盘   ║  实际时间: 10:23 ⚠ 延迟入场           ║
║  目标价: ≤1750    ║  成交价: 1768 ⚠ 超出目标价            ║
║  计划数量: 100股  ║  实际数量: 50股 ⚠ 仓位减半            ║
║  止损: 1650       ║  止损: 未设置 ❌ 违反原则#4            ║
╚═══════════════════╩═══════════════════════════════════════╝

执行偏差分析：
- 入场时间延误 ~53分钟（从开盘到10:23）
- 实际成交均价比计划高 1.03%，额外成本约 ¥900
- 仓位仅执行50%，若行情走好则收益减半
- 止损未设置，与原则#4冲突（这是本月第3次）

执行评分: 52 / 100
```

#### 3.3.2 持仓生命周期分析

对于一只股票的完整买卖周期，展示完整生命线：

```
600519 贵州茅台  本次持仓周期：2026-09-19 至 2026-09-26

价格走势 + 操作时间线：

1800 ┤                    ✂卖出 1789 (09-26)
1780 ┤         ●最高 1795
1760 ┤    ────────────────────────
1740 ┤  ●买入 1768 (09-19 10:23)
1720 ┤
     └────────────────────────────
      09-19  09-20  09-23  09-24  09-25  09-26

实际收益: +1.19% (+¥1,050，扣费后)
计划止损: 1650（实际未设置）
最大浮亏: -0.8%（09-20 盘中）

如果按计划执行（开盘买入100股）：
  潜在收益: +1.22% (+¥2,120）
  执行损耗: ¥1,070（延迟入场 + 仓位减半）
```

#### 3.3.3 盈亏归因分析

将盈亏拆解为可独立改进的分量：

```
本月盈亏归因（示例）

总收益: +¥8,320

归因拆解:
  方向判断贡献   +¥12,400   (预期方向正确率 72%)
  执行损耗      - ¥3,250   (入场时机延误 / 仓位减半)
  止损未执行    - ¥1,830   (3次应止损未止，多持亏损)
  手续费/印花   -    ¥890   (换手率偏高)
  ─────────────────────────
  实际到手      + ¥8,320

结论：判断能力在线，主要损耗来自执行纪律（占潜在收益 20%）
```

#### 3.3.4 交易习惯画像（从交割单中提取）

系统从交割单历史中自动计算客观的行为指标：

```
我的交易习惯（近90天，来自交割单）

入场习惯：
  开盘30分钟内入场占比  18%   ← 通常避开波动期
  尾盘30分钟入场占比    31%   ← 偏好尾盘择时
  平均入场时间          11:47

持仓习惯：
  平均持仓天数          4.2天
  最长单笔持仓          23天
  日内平仓次数          0次   ← 无日内交易
  持仓过周末比例        67%

出场习惯：
  止盈出场比例          42%   (主动止盈)
  止损出场比例          11%   (严重不足 ⚠)
  时间到期出场          31%   (到期卖出，无明确理由)
  情绪性卖出            16%   (当天大涨/大跌后卖出)

盈亏习惯：
  平均盈利单持仓         2.8天   ← 赢家卖太快
  平均亏损单持仓         7.1天   ← 输家持太久（处置效应）
  盈利单平均收益        +3.2%
  亏损单平均亏损        -4.8%
  盈亏比                0.67   ← 低于1.0，需改善
```

### 3.4 周度复盘报告

每周自动生成（也可手动触发），整合当周交割单 + 预期记录：

```
本周交易总结（2026-09-14 至 2026-09-19）

执行统计：
  共 N 笔成交 | 总成交额 ¥XXX | 净盈亏 ¥XXX

预期 vs 实际：
  预期录入 5 天 | 全部录入 ✅
  预期准确率 72% | 执行率 65%
  最大执行偏差：09-17 600519 仓位仅50%

本周规律：
  ✅ 方向判断稳定，连续4天大盘方向正确
  ⚠ 止损执行仍是短板（本周应止2次，实际0次）
  ⚠ 周四下午有情绪性加仓行为（无预期支撑）

Agent 本周点评：
  ...（见 Agent 评价模块）
```

## 四、成长仪表盘

### 4.1 设计原则

成长仪表盘显示的不是"赚了多少钱"，而是**你成为了更好的思考者和执行者的证据**。

盈亏受市场影响，不完全在你控制之内；但思维质量和执行纪律是可以被你控制的。

### 4.2 核心指标体系

```
我的成长仪表盘（近90天）

思维质量                          执行纪律
─────────────────────             ─────────────────────

### 4.4 我的交易方法论文档

当用户积累了足够多的记录后（建议90天），系统引导用户基于数据撰写自己的方法论：

```
我的交易方法论（基于过去 XX 天的数据）

我擅长的：
  - 趋势判断：方向准确率 XX%，强于均值
  - 周期：短线（3-5天）表现最佳，持仓超10天准确率下降
  - 市场状态：震荡市胜率 XX%，单边趋势市胜率 XX%

我的短板：
  - 止损执行：执行率仅 XX%，需要系统性改善
  - 反弹判断：下跌中的反弹判断准确率仅 XX%
  - 尾盘操作：尾盘入场平均表现比开盘入场差 XX%

我的原则（已验证有效的）：
  - 原则#X：...（违规后结果更差 XX%）
  - 原则#X：...

我需要回避的市场情景：
  - 大盘单日涨幅 > 2% 后追涨（历史亏损率 XX%）
  - 周五尾盘持有过周末（平均周末损耗 XX%）

我的最优交易状态：
  - 情绪指数 4-6
  - 有充足研究时间（> 60分钟）
  - 当前无持仓焦虑
```

这份文档不是一次写完的，而是随着数据积累，由系统辅助用户逐步填充和验证的**活文档**。

PsychologicalSnapshot

TradingPrinciple
├── id           UUID

├── rationale    Text，设立原因
├── is_active    bool
├── created_at   DateTime
├── updated_at   DateTime

PrincipleCheck
├── id               UUID
├── expectation_id   FK → UserExpectation
├── principle_id     FK → TradingPrinciple
├── is_violation     bool，是否违反
├── is_conscious     bool，是否有意识地例外
├── exception_reason Text | null，例外原因
└── created_at       DateTime
```

### 7.5 ExpectationTradeMatch（预期执行匹配）

```
ExpectationTradeMatch
├── id                   UUID
├── expectation_id       FK → UserExpectation
├── stock_expectation_id str（个股预期中的 ID）
├── trade_record_ids     List[UUID]（匹配到的交割单记录，可多笔）
├── match_status         Enum: full / partial / unexecuted / extra
│                         full=完全匹配, partial=部分执行
│                         unexecuted=计划未执行, extra=未计划的交易
├── price_deviation      float | null，价格偏差（实际 vs 计划）
├── quantity_ratio       float | null，实际数量 / 计划数量
├── timing_deviation_min int | null，入场时间偏差（分钟）
└── execution_score      float | null，执行评分 0-100
```
